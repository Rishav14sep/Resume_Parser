# Resume_Parser
An AI resume parser that converts PDF and DOCX resumes into structured JSON using LLaMA (via Groq), with a Streamlit UI for visualizing skills, experience, projects, and certifications.

 About the Project

This project demonstrates how transformer-based large language models can convert unstructured resume data into structured, usable information. It combines document text extraction (PDF and DOCX) with AI-driven parsing to build an efficient resume analysis tool.

 Features

📄 Upload resumes (PDF & DOCX)
 Extracts key information:

Name, Email, Phone
Skills
Education
Experience
Projects
Certifications
Summary

 Uses LLaMA 3 (via Groq) for intelligent parsing
 Outputs clean, structured JSON
 Interactive Streamlit UI for easy visualization
